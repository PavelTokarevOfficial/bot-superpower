# Бот «Суперспособность + дебафф»

Минимальный Telegram-бот на Node.js 24 и TypeScript. Пользователь пишет
суперспособность, а бот через ProxyAPI отвечает одним коротким смешным дебаффом.

## Возможности

- В личном чате отвечает на обычные текстовые сообщения без команд.
- В группе отвечает только на сообщения с `@username` бота или на reply к сообщению бота.
- В группе отправляет результат reply-ответом на исходное сообщение.
- Показывает `typing`, пока ожидает ProxyAPI.
- Ограничивает одного пользователя пятью AI-запросами в минуту в памяти процесса.
- Не сохраняет пользователей, сообщения или историю диалога.
- Показывает безопасную техническую диагностику по команде `/diag`.

## Требования

- Node.js 24
- npm
- Telegram bot token
- ProxyAPI key и положительный баланс

## Настройка

1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и
   username и сохраните выданный token.
2. Получите API key в кабинете ProxyAPI и пополните баланс.
3. Установите зависимости и создайте локальный env-файл:

```bash
npm install
cp .env.example .env
```

4. Заполните `.env`:

```env
TELEGRAM_BOT_TOKEN=ваш_telegram_token
PROXYAPI_API_KEY=ваш_proxyapi_key
PROXYAPI_MODEL=qwen/qwen3.8-omni-flash
```

Файл `.env` исключён из Git. Не публикуйте его и не передавайте токены другим людям.

## Запуск

Режим разработки с перезапуском после изменений:

```bash
npm run dev
```

Production-сборка и запуск:

```bash
npm run build
npm start
```

Дополнительные проверки:

```bash
npm run typecheck
npm run lint
npm test
```

Команда `/diag` в личном или групповом чате показывает текущую модель, баланс ProxyAPI,
ID чата и пользователя, Privacy Mode, лимиты, версию Node.js и uptime. Для отображения
баланса включите разрешение «Запрос баланса» в настройках ключа ProxyAPI. API-ключи и
Telegram token в диагностику не попадают.

Без обеих env-переменных приложение завершится с понятной ошибкой. Бот использует
long polling, поэтому отдельный HTTP-сервер и публичный URL не нужны.

## Работа в группах и Privacy Mode

По умолчанию BotFather включает Privacy Mode. Telegram гарантированно доставляет такому
боту команды и reply на его сообщения, но обычное текстовое сообщение вида
`@bot_username я умею летать` может не прийти приложению как update.

Если mention-сообщения не приходят, откройте в BotFather:

1. `/mybots` → выберите бота;
2. `Bot Settings` → `Group Privacy`;
3. нажмите `Turn off`;
4. удалите бота из уже созданной группы и добавьте снова.

Код всё равно фильтрует групповые сообщения и отвечает только при точном mention его
username либо при reply на собственное сообщение. Бот также игнорирует сообщения от
других ботов. Не выдавайте ему права администратора без необходимости: администраторы
группы получают больше сообщений независимо от Privacy Mode.

## Конфигурация MVP

Значения лимита текста (500 символов), rate limit (5 запросов в минуту), таймаута
Таймаут ProxyAPI (90 секунд) и технический лимит генерации (512 токенов с учётом
reasoning) находятся в `src/config/index.ts`, а выбранная модель задаётся переменной
`PROXYAPI_MODEL` в `.env`. Видимый ответ ограничивается одним предложением до 180
символов. Системный промпт вынесен в `src/prompts/debuff.ts`.
